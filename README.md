# PatternBreaker

AI 개발 도구를 활용하여 제작한 Unreal Engine 5 기반 보스 레이드 전투 프로토타입입니다.

<br>

## 1. 프로젝트 목표


AI를 실제 게임 개발 과정에 활용하고, 
요구사항 정의부터 기능 구현, 테스트 및 개선까지 
AI와 협업하는 개발 과정을 경험하고자 시작한 프로젝트입니다.


단순한 코드 생성을 넘어, AI가 생성한 결과물을 
실제 프로젝트에 적용하고 검증하는 과정에 중점을 두었습니다.

<br>

## 2. 구현 목표

### 보스 전투 시스템

- 상태 머신 기반 보스 공격 패턴 생성
- 공격 예고 및 범위 공격 시스템
- 보스 패턴에 따른 공격 및 회피 플레이
- 특정 상태에서만 보스에게 피해를 줄 수 있는 시스템


### 플레이어 전투 시스템

- 플레이어 이동 및 공격 시스템
- HP 및 피해 처리, 사망 판정
- 보스와 플레이어의 체력 실시간 UI 확인
-  보스 처치 및 전투 결과 처리

<br>

## 3. AI 활용 방식

### ChatGPT

- 프로젝트 요구사항 및 구현 방향 구체화
- 게임 시스템 설계 및 구현 방식 검토
- Unreal Engine 블루프린트 연동 가이드
- 개발 과정에서 발생한 문제 분석 및 해결 방법 탐색

### Codex

- 프로젝트 소스 코드 분석
- 요구사항에 따른 C++ 코드 작성 및 수정
- 빌드 수행 및 테스트, 컴파일 오류 확인

### 직접 수행

- 구현할 기능과 동작 조건 정의
- AI가 제안한 구현 방식 검토
- Unreal Engine 에디터에서 블루프린트 및 UI 구성
- 실제 플레이를 통한 기능 동작 검증 및 개선

<br>

## 4. 개발 환경

- Unreal Engine 5.8.4
- C++
- Blueprint / UMG
- ChatGPT / Codex

<br>

## 5. 향후 계획

### 랭킹 시스템

- 전투 클리어 기록을 저장하는 서버 및 DB 구축
- 개인 최고 기록 저장 및 갱신
- 유저별 점수를 확인할 수 있는 공용 랭킹 시스템


### 추가 검토 사항

- 멀티플레이 기반 협동 보스 레이드

<br>

## 6. 개발 현황

### v0.1 - 보스 전투 프로토타입

- 플레이어 및 보스 HP / 사망 처리
- 보스 범위 공격 및 공격 범위 표시
- 상태에 따른 보스 피격 판정
- 델리게이트 기반 HP UI 연동
- 플레이어 및 보스 테스트 공격

### v0.2 - 레이드 시스템 및 메인 메뉴

- 제한 시간 기반 레이드 진행 및 승리 / 패배 / 타임아웃 판정
- 레이드 남은 시간, 종료 결과 및 클리어 시간 UI 표시
- 메인 메뉴 UI 및 게임 시작 기능 구현
- 메인 메뉴와 보스 아레나 간 레벨 전환
- 레이드 종료 후 M키 수동 복귀 및 자동 복귀 기능 구현

### v0.3 - 랭킹 UI 구현 및 C++ 테스트 데이터 연동 준비

- 상위 랭킹 10개 단위 출력 및 이전/다음 페이지 이동 구현
- 빈 랭킹 안내 문구 및 동적 랭킹 행 생성 구현
- C++ 테스트 랭킹 데이터 조회 기능 구현
- 테스트 데이터 25개를 통한 10/10/5 페이지 출력 검증
